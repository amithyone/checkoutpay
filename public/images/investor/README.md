# Investor pitch photos

Drop image files here (JPG or PNG with the exact names below). The pitch page at `/investor` will pick them up automatically — no code change needed.

| Filename | Slot on page |
|----------|----------------|
| `hero.jpg` | Full-bleed hero background |
| `proximity-pay.jpg` | Proximity Pay product photo |
| `cheko-pos.jpg` | Cheko POS product photo |
| `checkoutnow-apps.jpg` | CheckoutNow apps photo |
| `team.jpg` | Team section |
| `retail-density.jpg` | Merchant / retail scene |
| `ask-background.jpg` | Optional closing / ask backdrop |

Recommended: wide hero ≥ 2400×1000, product slots ≥ 1600×1200. Keep file sizes under ~500KB when possible (compress before upload).

Until a file exists, the page shows a labeled blank space so you know where each photo goes.
