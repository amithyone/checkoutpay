# Bank logo library

SVGs here are vendored for CheckoutPay bank UI (originally from [Nigerian-Bank-Logos](https://github.com/Pariola-droid/Nigerian-Bank-Logos)).

- Map onto `banks` rows via Admin → Bank Logos or `php artisan banks:import-logos`
- Logos remain property of their respective owners; use only in product UI
- Add missing fintech logos via admin upload (stored under `storage/app/public/bank-logos/`)
