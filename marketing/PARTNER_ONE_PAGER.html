CheckoutPay + CheckoutNow

For merchants

  • Virtual accounts + automated bank-transfer matching
  • WhatsApp Pay Code on the same checkout
  • Hosted checkout, REST API, webhooks
  • WooCommerce via COPN
  • Invoices, tickets, memberships, rentals, payouts

1% + ₦50 per successful transaction

No setup / monthly on standard pay-as-you-go. Examples: ₦10k → ₦150 · ₦100k → ₦1,050

CTA: Create business account → check-outpay.com

For consumers

  • Same wallet on CheckoutNow app and WhatsApp (WALLET)
  • Send / receive, bank transfer, Ask for money, Save Together
  • Bills: airtime, data, electricity, cable, betting
  • USD virtual card from NGN (Tier 2 KYC; $7.50 setup)

CTA: app.check-outnow.com · Or message WALLET on WhatsApp

Why this stack

  • Bank-transfer-first — not card-only
  • Merchant pay-in and consumer wallet on one platform
  • Transparent fees — state 1% + ₦50, not “cheapest”
  • Nigeria-focused: NGN, local banks, COPN
